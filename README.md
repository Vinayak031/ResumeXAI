# ResumeXAI

## Explainable AI-Based Resume Evaluation and Job Matching System

ResumeXAI is an AI-powered web application designed to analyze resumes, compare them with job descriptions, calculate ATS compatibility scores, identify skill gaps, and provide personalized recommendations.

The system combines **Natural Language Processing (NLP), BERT/Sentence Transformers, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and Explainable AI (XAI)** to make resume evaluation more intelligent, transparent, and user-friendly.

Unlike traditional ATS systems that provide only a numerical score, ResumeXAI explains **why a resume received a particular score** and highlights the areas that can be improved.

---

## 🚀 Key Features

### 📄 Resume Parsing

- Upload resumes in PDF/DOCX format
- Extract resume text automatically
- Identify important resume sections
- Extract skills, education, experience, projects, and certifications

### 🎯 ATS Score

The system calculates an ATS compatibility score based on multiple factors:

- Skills matching
- Experience relevance
- Education
- Projects
- Keywords
- Resume formatting
